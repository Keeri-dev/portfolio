# Portfolio Website

## Accessibility Fixes

- Added a skip navigation link for keyboard users.
- Added visible focus indicators for links, buttons, and form controls.
- Added alt text to all images.
- Verified all text and background color combinations pass WCAG AA contrast.
- Added labels, fieldset, and legend elements to the contact form.

## Gestalt Principles

### Proximity
I used proximity by grouping related skill cards together.

### Similarity
I used similarity by giving all skill cards consistent colors, borders, and spacing.
